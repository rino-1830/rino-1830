# Boundary KV compression on Bonsai — experimental checkpoint (2026-09-27)

This branch is exploratory. Results below are controlled retrieval experiments, not a claim of general-language quality retention.

## Hypothesis under test

Treat the useful boundary between old context and future prediction as a small predictive region/state rather than a literal recent-token suffix.

## Bonsai-1.7B unpacked / HF experiments

- Full old prefix: 143 tokens plus 48 recent tokens.
- Learned block scorer: 2048 -> 64 -> 1, trained from future-loss KV-gradient teacher labels.
- The scorer sees only causal old-prefix hidden states at inference.
- Across three replication seeds, using 64 old tokens + 48 recent tokens:
  - full exact: 45.83%
  - learned block exact: 54.17%, 66.67%, 54.17% (mean 58.33%)
  - span-oracle exact: 70.83%
- 143-token-trained scorer extrapolated to a 512-token old prefix:
  - full: NLL 0.1908, exact 65%
  - learned 64 old: NLL 0.4020, exact 55%
  - learned 96 old: NLL 0.1339, exact 70%
  - uniform 96 old: NLL 0.9623, exact 5%

## Long-context oracle checks on mini PC

512 old tokens + 48 recent tokens.

Single relevant region:
- full: NLL 0.180, exact 55%
- 48-token relevant region: NLL 0.080, exact 75%

Four separated fact regions:
- full: NLL 0.1476, exact 55%
- recent-only: NLL 0.8817, exact 5%
- 48-token multi-region: NLL 0.1353, exact 60%
- 64-token multi-region: NLL 0.1190, exact 65%
- 48-token single-region: exact 20%
- uniform sampling: exact 0%

These controls indicate that multiple coherent predictive regions matter more than simply retaining the same number of uniformly sampled or recent KV entries.

## Packed Q1_0 Bonsai-1.7B, PrismML llama.cpp

The actual 1-bit GGUF was loaded and KV entries were evicted through llama_memory_seq_rm().

Direct post-prefill 48-token multi-region:
- full: NLL 0.1529, exact 58.33%
- multi-region 48: NLL 0.1961, exact 41.67%
- recent-only: NLL 5.0775, exact 0%
- uniform 48: NLL 4.1297, exact 0%

Fixed-capacity streaming:
- full context KV allocation: about 84 MiB in this configuration
- compressed streaming KV allocation: about 28 MiB
- physical KV memory reduction: 3x
- oracle-region streaming: NLL 0.4771, exact 41.67%

### Learned packed streaming selector

A seed-41 block scorer trained in the unpacked model was exported (~513 KiB) and evaluated inside llama.cpp from token hidden embeddings.

Keeping only the raw 8-token winning blocks failed:
- learned NLL 2.4238, exact 0%

The scorer nevertheless selected positions close to the four inserted facts. Each synthetic fact span was 11–13 tokens, so an 8-token retained block systematically truncated information.

Expanding each selected block into a 24-token region, without increasing the physical 28 MiB KV allocation, recovered:
- full: NLL 0.1223, exact 62.5%
- learned boundary: NLL 0.1197, exact 62.5%

On this small test, 1-bit weight compression and learned KV-region compression therefore composed with no observed loss.

## Packed Ternary Bonsai-1.7B

Direct multi-region budget sweep:
- full: NLL 0.0702, exact 87.5%
- 48 old: NLL 0.4875, exact 0%
- 64 old: NLL 0.2226, exact 62.5%
- 96 old: NLL 0.1729, exact 50%

The non-monotonic exact score is another sign that selection structure matters more than token count alone.

The Q1-trained learned region selector was transferred to packed Ternary without retraining.

Across two 4-question tables:
- full exact: 7/8 = 87.5%
- learned boundary exact: 6/8 = 75%
- first table: full NLL 0.0511, learned NLL 0.3253
- second table: full NLL 0.0898, learned NLL 0.0525

This is promising transfer evidence, but the sample is far too small for a general quality claim.

## Current interpretation

Evidence currently favors a **predictive multi-region boundary**:
1. importance is not well represented by a literal recent suffix;
2. independent token ranking is weaker than retaining coherent local regions;
3. learned region selection can transfer from unpacked to packed low-bit weights;
4. region expansion can recover information lost by overly narrow token/block selection without increasing the current physical KV allocation.

## Main remaining tests

1. Ternary Bonsai 2 27B packed runtime (5.9 GB model) on the same minimal protocol.
2. Natural-language / standard long-context benchmarks rather than synthetic identifiers.
3. Streaming scorer training that matches the compressed-state distribution instead of training only on full-history hidden states.
4. KV-cache quantization combined with region eviction.
5. Context-length scaling: estimate required retained region budget as old context grows.
